# Obfuscator

### [+] Created By <a href="https://github.com/onixsat">OnixSat</a>

### [+] Decription :
***Obfuscator is a tool to encrypt(obfuscate) or decrypt bash/shell script or compile python script. Compilation is available in variable or emoji.***

### [+] Installation

```apt install git python3 -y```

```git clone https://github.com/onixsat/obfuscator```

```cd obfuscator```

```bash requirements.sh```

```python3 secure.py```


### Or, Use Single Command
```
apt install git python3 -y && git clone https://github.com/onixsat/obfuscator && cd obfuscator && bash requirements.sh && python3 secure.py
```

#### Exemplo para obfuscar:
*** exemplo.sh ***
```
#!/usr/bin/env bash
read -n 6 -p "Enter the name : " name
echo -e "\nName : $name"
```

### Features:
1. Encrypt or Decrypt bash/shell file
2. Encrypt python file into emojies
3. Encrypt python file into custom variables
